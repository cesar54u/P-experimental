CONTEXTO PARA TU COMPANERO/A:
El codigo GDScript ya esta escrito (15 archivos .gd). NO hay que programar nada.
El trabajo consiste en crear escenas (.tscn), sprites, nodos en el editor de
Godot y conectar todo. Este documento explica EXACTAMENTE que hacer, click por
click.

Los scripts buscan nodos hijos por nombre exacto usando @onready. Si el nodo
no existe o se llama diferente, Godot dara error al ejecutar. Los nombres
criticos estan marcados con [NOMBRE EXACTO] en cada tarea.


================================================================================
TABLA DE SPRITES NECESARIOS
================================================================================

Antes de empezar con escenas, necesitan crear o conseguir estos sprites.
Pueden ser placeholder (cuadrados de colores) al principio y reemplazarlos
despues. Formato recomendado: PNG 64x64 o 32x32, fondo transparente.

Carpeta sugerida: res://assets/sprites/

  ARCHIVO                 QUE REPRESENTA           COLOR PLACEHOLDER
  -------                 ---------------          -----------------
  commander.png           Nave del jugador         Triangulo AZUL
  collector.png           Nave recolectora         Triangulo VERDE
  builder.png             Nave constructora        Triangulo AMARILLO
  enemy.png               Nave enemiga             Triangulo ROJO
  turret_base.png         Base de torreta          Circulo GRIS
  turret_gun.png          Canon de torreta         Rectangulo GRIS OSCURO
  command_center.png      Centro de comando        Hexagono BLANCO grande
  resource_crystal.png    Cristal de metal         Diamante CIAN
  bullet.png              Proyectil                Circulo pequeno BLANCO
  tile_ground.png         Suelo del mapa           Cuadrado MARRON 64x64
  tile_wall.png           Pared / obstaculo        Cuadrado GRIS OSCURO 64x64

COMO CREAR PLACEHOLDERS RAPIDOS EN GODOT:
  No necesitan software externo. Para cada sprite pueden:
  1. Crear un Sprite2D en la escena
  2. En el Inspector, en Texture: "New GradientTexture2D" o "New PlaceholderTexture2D"
  3. O usar un Polygon2D en vez de Sprite2D y dibujar un triangulo/circulo

  Alternativa: dibujar en Paint/GIMP un cuadrado de 64x64 de color solido,
  guardarlo como PNG en res://assets/sprites/.

TAREA 1: CREAR CARPETAS DEL PROYECTO
================================================================================

Responsable: Cualquiera de los dos (5 minutos)

En el panel FileSystem de Godot (abajo-izquierda), click derecho -> New Folder:

  res://scenes/          <- todas las escenas .tscn van aqui
  res://assets/          <- recursos visuales
  res://assets/sprites/  <- los PNG de sprites
  res://assets/fonts/    <- fuentes (opcional por ahora)

Las carpetas de scripts ya existen (autoload/, units/, structures/, etc.).


================================================================================
TAREA 2: CREAR ESCENA MAIN (la escena raiz del juego)
================================================================================

Responsable: ______________
Tiempo estimado: 15 minutos

PASOS:
  1. Menu superior: Escena -> Nueva Escena
  2. En el panel de escena (izquierda), click "Otro Nodo"
  3. Busca "Node2D" -> click Crear
  4. Renombrar el nodo raiz: doble-click sobre el nombre -> escribir "Main"

  5. Con "Main" seleccionado, agregar hijos (boton + arriba del arbol):
     a. Node2D         -> renombrar a "World"
     b. CanvasLayer    -> renombrar a "UI"

  6. Con "World" seleccionado, agregar hijos:
     a. Node2D         -> renombrar a "Map"
     b. Node2D         -> renombrar a "Resources"
     c. Node2D         -> renombrar a "Structures"
     d. Node2D         -> renombrar a "Units"

  RESULTADO - El arbol debe verse asi:
     Main (Node2D)
     +-- World (Node2D)
     |   +-- Map (Node2D)
     |   +-- Resources (Node2D)
     |   +-- Structures (Node2D)
     |   +-- Units (Node2D)
     +-- UI (CanvasLayer)

  7. Guardar: Ctrl+S -> navegar a res://scenes/ -> nombre: main.tscn

  8. Configurar como escena principal:
     Menu: Proyecto -> Ajustes del Proyecto -> Aplicacion -> Ejecutar
     -> "Escena principal" -> seleccionar res://scenes/main.tscn


================================================================================
TAREA 3: CREAR ESCENA RESOURCE NODE (el cristal de metal)
================================================================================

Responsable: ______________
Tiempo estimado: 20 minutos

PASOS:
  1. Escena -> Nueva Escena
  2. Nodo raiz: Area2D -> renombrar a "ResourceNode"

  3. ADJUNTAR SCRIPT (NO crear uno nuevo):
     a. Click derecho sobre ResourceNode -> "Adjuntar Script"
     b. Desmarcar "Crear script nuevo" / click en carpeta
     c. Navegar a: res://resources/resource_node.gd
     d. Click Abrir / Cargar

  4. Con ResourceNode seleccionado, agregar hijos:

     a. CollisionShape2D
        - En el Inspector (derecha), buscar "Shape"
        - Click el dropdown -> "Nuevo CircleShape2D"
        - Click sobre el circulo azul en el viewport y arrastra para radio ~30-40 px

     b. Sprite2D
        - En el Inspector, buscar "Texture"
        - Arrastrar res://assets/sprites/resource_crystal.png al campo Texture
        - O si no tienes sprite: click Texture -> "Nuevo PlaceholderTexture2D"
          y cambiar el color en Modulate (Inspector) a CIAN

  5. CONFIGURAR GRUPO (muy importante):
     a. Con ResourceNode seleccionado, ir a la pestana "Nodo" (al lado de Inspector)
     b. Click en la sub-pestana "Grupos"
     c. En el campo de texto escribir: resource
     d. Click "Agregar"
     e. Debe aparecer "resource" en la lista de grupos

  6. CONFIGURAR EXPORT VARS:
     a. Con ResourceNode seleccionado, en el Inspector buscar "Amount"
     b. Poner valor: 500 (ya deberia estar por defecto)

  7. Guardar como: res://resources/resource_node.tscn

================================================================================
TAREA 9: CREAR EL MAPA CON NAVEGACION
================================================================================

Responsable: ______________
Tiempo estimado: 30-45 minutos
NOTA: Esta es la tarea mas delicada. Sin navegacion, NINGUNA nave se mueve.

PASOS:
  1. Abrir res://scenes/main.tscn

  2. OPCION A - Mapa con TileMapLayer (recomendada para mapa final):
     a. Seleccionar Main/World/Map
     b. Agregar hijo: TileMapLayer
     c. En el Inspector: TileSet -> "Nuevo TileSet"
     d. Click en el TileSet creado para abrir el editor de TileSet (panel inferior)
     e. En el editor de TileSet:
        - Click "+" para agregar textura -> seleccionar tile_ground.png
        - Tamano de tile: 64x64 (o el tamano de tu sprite)
     f. Volver al TileMapLayer y pintar el suelo del mapa usando la herramienta
        de pincel (panel inferior "TileMap")
     g. Pintar un area de al menos 20x15 tiles

  3. OPCION B - Fondo simple con Sprite (placeholder rapido):
     a. Seleccionar Main/World/Map
     b. Agregar hijo: Sprite2D
     c. Texture: Crear "New GradientTexture2D" de 1920x1080 color marron oscuro
     (Esto solo es un fondo. Igual necesitas el NavigationRegion2D del paso 4.)

  4. AGREGAR NAVEGACION (obligatorio en ambas opciones):
     a. Seleccionar Main/World/Map
     b. Agregar hijo: NavigationRegion2D
     c. En el Inspector, buscar "Navigation Polygon"
     d. Click -> "Nuevo NavigationPolygon"
     e. En la barra superior del viewport aparecen herramientas de navegacion
     f. Click en "Crear nuevo poligono" (icono de lapiz con puntos)
     g. Dibujar un rectangulo grande cubriendo toda el area jugable:
        - Click en cada esquina para poner puntos
        - Click derecho o Enter para cerrar el poligono
     h. BAKE: Click en el boton "Bake NavigationPolygon" (barra superior)
        Debe aparecer el area pintada de un color semi-transparente

  5. VERIFICACION:
     - El area azul/verde semi-transparente debe cubrir donde quieras que
       caminen las naves
     - Si hay obstaculos, dibuja poligonos internos para excluirlos
     - Si no ves color semi-transparente, el bake fallo o el poligono esta mal

ERRORES COMUNES Y SOLUCIONES

ERROR: "Cannot get path of node as it is not in a SceneTree"
CAUSA: Intentas acceder a un nodo antes de que este en el arbol.
FIX:   Mover la logica a _ready() o usar call_deferred().

ERROR: "NavigationAgent2D could not find a NavigationMap"
CAUSA: No hay NavigationRegion2D en la escena, o no tiene bake.
FIX:   Ir a main.tscn -> seleccionar NavigationRegion2D -> hacer Bake.

ERROR: "Null instance" al buscar grupo "command_center"
CAUSA: El CommandCenter no esta instanciado en main.tscn, o el script
       no hace add_to_group("command_center").
FIX:   Verificar que command_center.tscn esta instanciado en Structures.

ERROR: El Collector se queda quieto
CAUSA: Probablemente no hay nodos en el grupo "resource".
FIX:   Seleccionar cada ResourceNode en main.tscn -> Nodo -> Grupos ->
       verificar que tiene "resource".

ERROR: "Cannot find node MetalLabel" (o similar)
CAUSA: El nodo hijo no tiene el nombre exacto que busca el @onready.
FIX:   Renombrar el nodo hijo al nombre exacto que indica el error.

ERROR: Las naves se mueven pero atraviesan todo
CAUSA: Las capas de colision no estan configuradas.
FIX:   En cada CharacterBody2D, ir a Inspector -> Collision -> Layer/Mask
       y configurar que capas usar (capa 1 para todo al inicio esta bien).
